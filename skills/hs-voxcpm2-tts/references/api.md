## 0. 一句话定位
VoxCPM 是 OpenBMB 的 **tokenizer-free 语音生成模型族**。VoxCPM2 是当前推荐版本，输出 **48 kHz**，支持 30 种语言 + 9 种中文方言，可做：
- **Voice Design**（文字描述声音，无需参考音）
- **Controllable Voice Cloning**（参考音克隆音色 + 文字微调风格）
- **Ultimate Cloning**（参考音 + 转写，最高相似度）

许可证 Apache-2.0（可商用）。

## 3. Python API

### 3.1 加载
```python
from voxcpm import VoxCPM
model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)   # 或本地目录
# 本机离线：VoxCPM.from_pretrained("<本地权重目录>", load_denoiser=False, device="mps", optimize=False)
sr = model.tts_model.sample_rate   # 48_000 for VoxCPM2
```
- `load_denoiser=False`：跳过 16k 去噪器，清音合成无需它（更快、省显存）。
- `device`：`"mps"` / `"cpu"` / `"cuda"` / `"cuda:0"`。Apple Silicon 用 `"mps"`。
- `optimize=False`：关闭 `torch.compile`（compile 仅 CUDA 有效，MPS 上会拖慢或报错）。

### 3.2 `model.generate()` 全部参数
| 参数 | 类型 | 说明 |
|------|------|------|
| `text` | str | 必填。要合成的文本。**Voice Design 模式**把声音描述用括号写在最前面，如 `"(A young woman, gentle and sweet voice)Hello..."`。 |
| `reference_wav_path` | str | 克隆音色用的参考音频路径（CLONE / Controllable Clone）。 |
| `prompt_wav_path` | str | **Ultimate Cloning** 用：作为「续写」参考的音频。 |
| `prompt_text` | str | Ultimate Cloning 用：参考音频的转写文本。 |
| `cfg_value` | float | 分类器自由引导强度。官方示例用 `2.0`；本 skill 克隆模式用 `1.8`。越大越贴近条件、越稳。 |
| `inference_timesteps` | int | 扩散步数。官方示例 `10`；本 skill 质量模式 `30`、草稿 `12`。越大越保真越慢。 |
| `seed` | int | 随机种子（如 `42`），用于可复现。 |

返回：`wav`（numpy 数组，shape `(samples,)`，采样率 `model.tts_model.sample_rate`）。

### 3.3 四种合成模式（官方示例）
```python
import soundfile as sf

# (a) 基础 TTS / 默认声音
wav = model.generate(text="VoxCPM2 is the recommended release.", cfg_value=2.0, inference_timesteps=10, seed=42)
sf.write("demo.wav", wav, model.tts_model.sample_rate)

# (b) Voice Design（文字描述声音，无参考音）
wav = model.generate(text="(A young woman, gentle and sweet voice)Hello, welcome to VoxCPM2!", cfg_value=2.0, inference_timesteps=10, seed=42)
sf.write("voice_design.wav", wav, model.tts_model.sample_rate)

# (c) Controllable Voice Cloning（参考音克隆 + 文字微调风格）
wav = model.generate(text="This is a cloned voice generated by VoxCPM2.", reference_wav_path="path/to/voice.wav")
wav = model.generate(text="(slightly faster, cheerful tone)This is a cloned voice with style control.", reference_wav_path="path/to/voice.wav", cfg_value=2.0, inference_timesteps=10, seed=42)
sf.write("controllable_clone.wav", wav, model.tts_model.sample_rate)

# (d) Ultimate Cloning（最高相似度：prompt 音频 + 转写 + 同一参考音）
wav = model.generate(text="This is an ultimate cloning demonstration using VoxCPM2.",
                     prompt_wav_path="path/to/voice.wav",
                     prompt_text="The transcript of the reference audio.",
                     reference_wav_path="path/to/voice.wav")
sf.write("hifi_clone.wav", wav, model.tts_model.sample_rate)
```

### 3.4 流式生成
```python
import numpy as np
chunks = []
for chunk in model.generate_streaming(text="Streaming text to speech is easy with VoxCPM!"):
    chunks.append(chunk)
sf.write("streaming.wav", np.concatenate(chunks), model.tts_model.sample_rate)
```

## 4. 命令行 CLI
```bash
# Voice Design
voxcpm design --text "VoxCPM2 brings studio-quality multilingual speech synthesis." --output out.wav
voxcpm design --text "..." --control "Young female voice, warm and gentle, slightly smiling" --seed 42 --output out.wav

# Voice Cloning
voxcpm clone --text "This is a voice cloning demo." --reference-audio path/to/voice.wav --output out.wav

# Ultimate Cloning
voxcpm clone --text "..." --prompt-audio path/to/voice.wav --prompt-text "reference transcript" --reference-audio path/to/voice.wav --output out.wav

# 批量
voxcpm batch --input examples/input.txt --output-dir outs

# 时间戳（需 voxcpm[timestamps]）
voxcpm design --text "..." --output out.wav --timestamps --timestamp-level word --timestamp-language en
voxcpm design --text "欢迎使用 VoxCPM2。" --output out.wav --timestamps --timestamp-level char --timestamp-language zh

voxcpm --help
```
> 本机离线优先用 Python API + 本地权重（见 `workflow.md`），CLI 同理需保证 `from_pretrained` 指向本地目录。

## 6. 高性能 / 生产后端（参考，本机非必需）
- **Nano-vLLM**：`from nanovllm_voxcpm import VoxCPM; server = VoxCPM.from_pretrained(model="/path", devices=[0]); chunks = list(server.generate(target_text="...")); server.stop()`
- **vLLM-Omni**：`vllm serve openbmb/VoxCPM2 --omni --port 8000` → `curl http://localhost:8000/v1/audio/speech -d '{"model":"openbmb/VoxCPM2","input":"...","voice":"default"}' --output out.wav`
- **llama.cpp-omni（C++ 端侧）**：需 GGUF（BaseLM F16/Q8_0 + Acoustic F16），构建后 `./voxcpm2-cli -t "..." -o out.wav VoxCPM2-BaseLM-Q8_0.gguf VoxCPM2-Acoustic-F16.gguf`，克隆加 `-r speaker.wav`，终极克隆加 `--prompt-wav/--prompt-text`。
